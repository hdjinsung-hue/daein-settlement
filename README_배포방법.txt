- manifest.webmanifest
- icon-192.png

- favicon-32.png
- .nojekyll

[배포 핵심]
1. GitHub 새 저장소 생성
2. 위 파일들을 저장소 최상위(root)에 업로드
3. Settings > Pages
4. Build and deployment: Deploy from a branch
5. Branch: main / (root) > Save
6. 표시되는 https://계정명.github.io/저장소명/ 주소 접속

[휴대폰 바로가기]
Android Chrome: 메뉴(⋮) > 홈 화면에 추가 또는 앱 설치
iPhone Safari: 공유 > 홈 화면에 추가

※ index.html이 반드시 저장소 최상위에 있어야 합니다.
